# Status

**v1.1 — verified SDK syntax baseline and reproducible documentation**

Updated: **2026-09-30**. Native compilation baseline: **Adobe SDK 25.6, macOS arm64, C++17**.

## Evidence

- Native translation units and foundation headers pass strict syntax/type checks against a locally installed Adobe SDK 25.6.
- Python tests cover incomplete parsing, missing inputs, ignored comments, conflicting tables and function-field reordering.
- Foundation tests exercise resource release, moves, acquisition failure, undo balance and callback exceptions.
- MASTER, checksum manifest and MkDocs staging are generated by `scripts/build_docs.py`; CI checks freshness and builds the site.
- The header indexer fails closed on unsupported declarations. Real SDK indexing is currently **incomplete**, not a successful SDK validation.

## Verification boundaries

Syntax compilation does not establish linking, PiPL correctness, host loading, rendered pixels or MFR safety. No native binary in this edition is labelled host-verified. Windows compilation and AE host tests remain pending. An installed AE application is not evidence of a successful test.
